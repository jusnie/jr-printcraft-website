Admin Dashboard

Finish setup first

This admin dashboard needs Supabase connected before it can work. Open supabase-config.js and fill in your SUPABASE_URL and SUPABASE_ANON_KEY, then run the SQL in supabase-admin-setup.sql once inside your Supabase project's SQL Editor. Full steps are in the comments at the top of supabase-config.js.

Owner Login

Sign in with the admin account you created in Supabase.

Reset your password

Enter your admin email and we'll send you a secure reset link.

Set a new password

Choose a new password for your admin account.

Manage Products

Update the price and photo for any item. Changes appear on the live site immediately.

Customer Feedback

Feedback submitted from the website's Feedback section, newest first.

Branding, Gallery & Ornament Designs

Update the logo, hero photo, the 4 showcase gallery photos, and the 4 Ceramic Ornament designs customers flip through using the "Look 1 / 2 / 3 / 4" buttons. Choose a new photo, preview it, then save.
